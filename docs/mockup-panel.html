④ Gestion du contexte entre phases
PrincipeChaque rôle reçoit un handoff minimal, jamais le transcript.
Budget par handoff : 8k tokens (avant : ~70k, dont 256 Ko de contexte dépôt).
  • 1Handoff par rôle. Chaque rôle reçoit uniquement l'artefact du précédent.
  • 2Diff, pas snapshot. git diff --stat + diff borné ; l'agent lit le reste avec ses outils.
  • 3Artefacts compacts. Sorties structurées summary / changes / remaining / issues.
  • 4Référence, pas copie. Logs de tests en fichier ; le prompt garde les 30 dernières lignes en échec + le chemin.
  • 5Pas de doublon. Le plan est stocké structuré et rendu par le panneau, pas recopié en JSON dans le fil.
  • 6Budget mesuré. Tokens comptés avant envoi, troncature par priorité, badge « Handoff » dans l'UI.
  • 7Session fraîche par cycle. Le builder repart avec plan + issues à chaque correction.
